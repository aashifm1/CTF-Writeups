TCS HackQuest is a premier, multi-round hiring Capture-The-Flag (CTF) competition hosted by Tata Consultancy Services to recruit top cybersecurity talent through intense online and in-person challenges spanning web security, digital forensics, and reverse engineering.
## Progression

- Round 1: Online CTF featuring beginner to expert challenges with a mandatory accompanying report submission detailing methodology and screenshots.
- Round 2: Advanced remotely proctored online challenge requiring camera verification.
- Final Round: In-person hackathon/assessment at a TCS campus.

## Core Domains & Challenges
• **Web Application Security**: Source code inspection, hidden JavaScript, secret API calls, client-side vulnerabilities, Local File Inclusion (LFI), path traversal, and JWT manipulation.
• **Digital Forensics & Steganography**: Analyzing images/files using tools like binwalk, exiftool, strings, zsteg, and QR code reconstruction.
• **Cryptography & Encoding**: Decodable strings utilizing Base64/Base32, hex, Caesar ciphers, ROT rotations, and periodic table chemical symbols.
• **General Skills**: Python scripting for rapid text automation, decoding, and basic network or password analysis.
